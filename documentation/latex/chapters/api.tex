\chapter{HTTP API reference}
\label{ch:api}

The running instance publishes its own schema at \route{/docs} (Swagger UI) and
\route{/redoc}, generated from the pydantic models in \file{app/api\_models.py}.
That is the authority on exact field types for the version you have. This
chapter is the map: what exists, what it is for, and the parameters that matter.

\section{Conventions}

\begin{itemize}
\item Request bodies are JSON unless the endpoint takes a file, in which case it
is \code{multipart/form-data}.
\item Long operations return \code{202} with a job record; poll
\route{GET /jobs/\{job\_id\}} (Section~\ref{sec:jobs-api}).
\item When authentication is enabled, every endpoint except \route{/health},
\route{/login}, \route{/logout} and \route{/favicon.ico} requires the session
cookie. An HTML \code{GET} without one redirects to \route{/login}; anything
else gets \code{401}.
\item Errors are FastAPI's \code{\{"detail": "..."\}}.
\end{itemize}

A typical job flow:

\begin{shellblock}
$job = Invoke-RestMethod -Method Post http://127.0.0.1:8000/embeddings/rebuild
Invoke-RestMethod "http://127.0.0.1:8000/jobs/$($job.job_id)"
\end{shellblock}

\section{Examples}

Search:

\begin{shellblock}
Invoke-RestMethod "http://127.0.0.1:8000/search?query=fren+pedali&mode=hybrid&limit=5"
\end{shellblock}

Ingest a file:

\begin{shellblock}
$form = @{ file = Get-Item .\rapor.pdf }
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/ingest -Form $form
\end{shellblock}

Ask a grounded question:

\begin{shellblock}
$body = @{
    message        = "BIG-E konfor raporunda hangi parkurlar var?"
    assistant_mode = "report"
    limit          = 5
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/chat `
    -ContentType "application/json" -Body $body
\end{shellblock}

Record a review decision:

\begin{shellblock}
$body = @{
    document_id = 12
    finding_key = "9f2c1a77b3e40d18"
    rule_id     = "captions.sequence"
    decision    = "confirmed"
    note        = "Tablo 4 gercekten atlanmis."
    reviewer    = "analiz"
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/report-review/decisions `
    -ContentType "application/json" -Body $body
\end{shellblock}
