% --- inline shorthands -----------------------------------------------------
% Names like CATIA_SKILL_CMC_TIMEOUT_SECONDS are single unbreakable words, and
% set solid in a narrow table column they run past the rule. Inside these
% macros an underscore becomes a legal breakpoint, so a long identifier wraps
% at a seam the reader already reads as one. \_ is a control sequence, so
% giving it a new meaning inside the group takes effect even though the
% argument was tokenized earlier.
\newcommand{\ttbreakable}[1]{{\small\ttfamily\def\_{\textunderscore\allowbreak}#1}}
\newcommand{\code}[1]{\ttbreakable{#1}}
\newcommand{\env}[1]{\ttbreakable{#1}}
\newcommand{\route}[1]{\ttbreakable{#1}}
\newcommand{\file}[1]{\ttbreakable{#1}}
